A free, hands-on learning platform for DevOps, cloud and AI. Guided skill tracks run from Linux, shell scripting and Git through Docker, Kubernetes, Terraform, AWS, Azure and Claude. Learners practise against a deterministic simulated Kubernetes cluster in the browser, clearly labelled Simulation Mode.

Lessons, scenario quizzes and hands-on work. Grading checks the state you produced, not the command you typed.
